## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/XinDi-Technology/rspress-theme-aim.git
cd rspress-theme-aim
```

### 2. 安装依赖

```bash
pnpm install
```

### 3. 启动开发服务器

```bash
pnpm dev
```

### 4. 开始开发

在浏览器中打开 `http://localhost:3000/rspress-theme-aim/` 查看效果。
