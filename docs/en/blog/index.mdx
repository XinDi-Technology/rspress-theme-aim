# Blog

Welcome to the Rspress Theme AIm blog page, where we share the latest technical articles, tutorials, and project updates.

## Latest Articles

Rspress Theme AIm is a documentation site theme based on Rspress, providing rich features and an excellent user experience.

### Key Features

- **Zero Local Setup**: One-click deployment via GitHub Pages
- **Multi-language Support**: Built-in Chinese and English switching
- **Copyright Information**: Support for custom company names and links
- **Filing Information**: Support for ICP filing and public security filing
- **SEO Optimization**: Built-in SEO tags and sitemap
- **Blog Functionality**: Support for categories, tags, and timeline

### How to Use the Blog Feature

1. **Create Blog Posts**: Create MDX files in the `docs/en/blog` directory
2. **Add Frontmatter Metadata**: Add title, date, categories, and tags at the beginning of articles
3. **Visit Blog Page**: Access the blog list via the `/blog` path
